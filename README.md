# Лабораторная работа №7. Векторизация вычислений

Три варианта программы, которые обращают матрицу A размером N×N разложением в ряд:

```
A⁻¹ = (I + R + R² + … + R^(M−1)) · B
B   = Aᵀ / (‖A‖₁ · ‖A‖∞)
R   = I − B·A
```

‖A‖₁ — максимальная сумма модулей по столбцам, ‖A‖∞ — по строкам, I — единичная матрица, M — число членов ряда. Элементы матриц имеют тип `float`.

## Содержимое

| Файл | Описание |
|---|---|
| `plain.c` | вариант без ручной векторизации: умножение в порядке циклов i-k-j, разбитое на блоки 256×256 |
| `sse.c` | ручная векторизация встроенными функциями компилятора (SSE intrinsics, `__m128`) |
| `blas.c` | матричные операции из библиотеки BLAS: `cblas_sgemm`, `cblas_saxpy`, `cblas_sasum` |
| `CMakeLists.txt` | сборка всех трёх программ |

## Требования

- компилятор GCC с поддержкой SSE (любой процессор x86-64);
- библиотека OpenBLAS — только для `blas.c`:
  - Windows (MSYS2 UCRT64): `pacman -S mingw-w64-ucrt-x86_64-openblas`
  - Ubuntu / Debian: `sudo apt install libopenblas-dev`

## Сборка

Через CMake (или просто открыть папку в CLion):

```bash
cmake -S . -B build
cmake --build build
```

Или вручную:

```bash
gcc -O3 -o plain plain.c -lm
gcc -O3 -o sse   sse.c   -lm
gcc -O3 -o blas  blas.c  -lopenblas -lm
```

## Запуск

```bash
./plain [N] [M]
```

По умолчанию N = 2048, M = 10. Программа печатает время обращения матрицы и ошибку `max |A*X - I|`: чем ближе к нулю, тем точнее найдена обратная матрица.

```
N = 2048, M = 10, time = 14.394 s
max |A*X - I| = 6.702638e-02
```

Чтобы сравнение было честным, BLAS нужно запускать в одном потоке:

```bash
OPENBLAS_NUM_THREADS=1 ./blas
```

## Проверка правильности

Запустите все три программы с одинаковыми небольшими параметрами, например `13 50` или `64 50`:

- ошибка `max |A*X - I|` у всех трёх вариантов совпадает;
- при увеличении M ошибка уменьшается, то есть ряд сходится к обратной матрице.

## Результаты

N = 2048, M = 10, флаг `-O3`:

| Вариант | Время, с | Ускорение |
|---|---|---|
| без ручной векторизации | 14,394 | 1,0 |
| SSE intrinsics | 11,971 | 1,2 |
| BLAS (OpenBLAS) | 0,751 | 19,2 |

Без оптимизации компилятора (Debug): 390,0 с, 139,9 с и 0,695 с соответственно.
